```

    写入方字段门（PUTFIELD f_135391_ / f_146795_ / f_146801_ / f_19825_ …）
    方法调用包装（setHealth / setRemoved / remove / kill / die）
    读侧替换 readFloat

    ✅ 加载 + 金库（VirtualAlloc + PAGE_READONLY + 影子副本 + 校验和 + VEH）
    ✅ JVMTI 能力探针（只 GetEnv + GetPotentialCapabilities，不改表）
    ❌ JNI 表 hook（install）—— 会崩 defineClass，已停用
```

## 4. 我们犯过的错（血泪清单，别再犯）

| 错 | 表现 | 教训 |
|---|---|---|
| 读侧掩护值 1e9 灌进自家账本 | `reindex_failed ... ledger=1.0E9` | 掩护值必须只对"外人"，自家读取要 trusted |
| 在 `Entity`/`SynchedEntityData` 上装门 + `COMPUTE_FRAMES` | `jvm.dll+0x7b4277`（C1）、`jvm.dll+0xcbf1`（G1 GC）崩溃 | 原版巨型类不要改字节码；§0.1 早有此规则 |
| 原地改共享 JNI 表 | `defineClass` 崩（pc=0） | 只能改私有表/代理 env |
| agent jar 排除 `GuardRuntime.class` 但先用它 | `NoClassDefFoundError: sanctuary/agent/GuardRuntime` | `appendBootstrapStub` 必须是 agentmain 第一句 |
| 周期重打触发 AV `TailGuard` | `patched` 25,514 行，服务端线程饿死，`ModernFix watchdog` | 重打会"喂养"对手的恢复循环 |
| DiskShield 给所有 jar 打 `dos:readonly` | PCL 报"没有读取权限" | 磁盘层默认不要锁文件 |
| `EntityType.create` 的 tag 门压栈不平衡 | 物品放不出实体 | 静态方法 slot0 是第一个参数，别再压 `this` |
| 用简单名找 SRG 方法（`getUUID`） | `isExempt` 恒 false → 所有门放行（`gate#… protected=0`） | 运行时是 `m_20148_`；用字段 `f_19820_` 读 UUID 更稳 |
| 误把"傀儡活着"归因于 UUID 轮换 | 实际 agent 没挂，是 mod 层重建 | 先看 `agent=ATTACHED` 与 `IDENTITY-ROTATED` 计数 |
| 用 PowerShell 正则改 Java 源码 | 插入字面量 `` `r`n ``、重复方法、编译失败 | 改 Java 用 edit 工具，别用字符串替换 |

## 6. 下一步（按优先级）

1. **mod 层补 `DISCARDED`**：`RemovalGuard.allow` 现在只拦 KILLED；给"玩家回收"留 5–10 tick 豁免窗口，其余 DISCARDED 拦下。这堵的是 toaru `discard()` 那条路。
2. **mod 层做身份轮换**：`Entity.setUUID`（`m_20084_`）纯反射；门拦下时轮换 + 旧 UUID 进 `FAKE_DEAD` + 物品放出前洗 UUID（`EntityType.create` 可在 mod 层用 mixin 包一层，不需要 agent）。
3. **拆索引**：`ClassInstanceMultiMap.remove` / `EntitySection.m_188355_` 用 **mixin**（mod 层，非 agent），避免 COMPUTE_FRAMES。
4. **`actuallyHurt`**：mod 层 mixin 或 `DamageAdmission` 扩展。
5. **DLL 代理 env**（高风险，最后做）：hook `JavaVM->GetEnv` 返回代理 `jvmtiEnv`，只改 `RedefineClasses`/`RetransformClasses`/`GetClassBytes`；先做"只记日志不拦截"版本，确认稳定再开拦截。目标：让别人对关键类的 redefine 无效，或让它的"原始字节"就是我们的补丁。
6. **JVMTI 字段断点**：`caps` 探针已就绪，`fieldWatch=true` 时可用；但它只覆盖 Java/JNI 写，裸内存写无效。

## 7. 测试协议（每次改完必须跑）

1. 启动，确认 `latest.log` 有 `[Sanctuary] agent=ATTACHED`；
2. `sanctuary-agent.log` 应有 `bootstrap stub appended` / `installed` / `scrubber started`；
3. 进世界（记录 `Starting integrated` → `Time elapsed` 耗时，正常 < 10s）；
4. `/ga guard dump 32`：确认傀儡数量；
5. 逐把武器右键，再 `dump`，对比数量与 `raw=`；
6. `/ga guard watch` 看收敛计数器；
7. 关注日志关键词：`DATA-DENIED` / `REMOVE-DENIED` / `INDEX-DENIED` / `HURT-DENIED` / `IDENTITY-ROTATED` / `SPAWN-UUID-WASHED` / `patched` 速率 / `Thread dump`。
